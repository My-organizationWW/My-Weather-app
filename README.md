# 🌤️ My Weather App — Моя погода

[![Build APK](https://github.com/werxuiiika/My-Weather-app/actions/workflows/android-build.yml/badge.svg)](https://github.com/werxuiiika/My-Weather-app/actions)

Лёгкое адаптивное приложение погоды для Android на **React Native (Expo SDK 58)**.
Особенность проекта: весь цикл — от кода до релизного APK — делается **с мобильного устройства** (Termux + OpenCode).

## ✨ Ключевые особенности

- 🔍 **Умный мультиязычный поиск**: запрос идёт на языке приложения → fallback на английский → транслитерация кириллицы в латиницу. Находит даже мелкие города вроде Fitzgerald по запросу «Фицджералд».
- 📍 **Честная геолокация**: корректная обработка разрешений Android 12+, кастомный диалог с кнопкой «Открыть настройки», поддержка точной и приблизительной геолокации.
- 🎨 **Адаптивность**: масштабирование шрифтов, светлая/тёмная/авторская темы, SafeArea.
- 🌍 **Локализация**: RU/EN через i18next с переключением на лету.
- 🌫️ **Раздел «Явления»**: поиск городов из встроенной базы по погодному явлению (снег, туман, гроза…).
- 🏙️ **Управление городами**: drag-and-drop с физикой в духе Xiaomi (overlap-and-swap по 75%, пружин нет — строгий ease-in-out), отдельная закреплённая карточка геолокации, мультивыбор с «Выбрать все», опциональное подтверждение удаления.
- ☀️ **Живые иконки**: солнце вращается в почасовом и недельном прогнозе, а не только на главном экране.
- 🧰 **Crash reporting**: непойманные ошибки пишутся в `Download/WeatherLogs`, в приложении есть просмотрщик и экспорт логов (вход — 7 тапов по версии в «О приложении»).
- 🤖 **CI/CD**: GitHub Actions собирает release-APK при каждом пуше в main и публикует GitHub Release по тэгу `v*`.

## 🛠️ Стек

React Native · Expo SDK 58 · JavaScript (ES6+) · Yarn Classic · Open-Meteo API (без ключей) · i18next · React Navigation · GitHub Actions

## 🚀 Запуск

```bash
git clone https://github.com/werxuiiika/My-Weather-app.git
cd My-Weather-app
yarn install
npx expo start --clear
```

APK: вкладка Actions → последний успешный ран → артефакт `app-release.apk`.

## 📂 Структура

```text
├── App.js / WeatherApp.js       # точка входа, главный экран
├── CityListScreen.js            # управление городами
├── DraggableCityCard.js         # карточка города с drag-and-drop
├── CurrentLocationCard.js       # закреплённая карточка геолокации
├── ConfirmDeleteModal.js        # компактный диалог удаления
├── WeatherPhenomenonFinder.js   # раздел «Явления»
├── SettingsScreen.js            # настройки
├── components/                  # GlobalErrorBoundary, CrashLogViewer
├── utils/                       # crashLogger, dragTrace, plural
├── ThemeContext / FontSizeContext / LoadingContext / SettingsContext
├── locales/ (ru.json, en.json)  # переводы
├── geocoding.js                 # поиск с fallback и транслитерацией
├── assets/                      # иконки, splash
└── .github/workflows/           # CI/CD
```

## 📦 История версий

<details open>
<summary><b>1.0.23 — «Живые карточки»</b> (текущая)</summary>

Полный редизайн карточек городов: погодные градиенты, «стеклянный» блик и анимированные иконки. Перетаскивание переехало на ячейки списка — карточки больше не теряют нажатия после перестановки. Приложение собрано на Expo SDK 58.

### 🃏 Новые карточки городов
- Погодные градиенты для каждого состояния: ясно, облачно, туман, дождь, снег, ливень и гроза — отдельные палитры днём и ночью
- «Стеклянный» радиальный блик, тонкая светлая рамка и глубокая тень
- Живые иконки погоды: солнце и снежинка вращаются, капли дождя падают, луна мягко пульсирует, туман плывёт, молния периодически вспыхивает
- Микроанимации уважают системную настройку «уменьшить движение»
- Плавный подъём карточки при перетаскивании: масштаб, тень и слой

### ✋ Перетаскивание без промахов
- Движение перенесено с карточки на ячейку FlatList — зона нажатия двигается вместе с визуалом
- После любого количества перестановок все карточки остаются кликабельными
- Стабильный порядок ячеек: при отпускании нет нативного пересчёта layout и мерцания
- Соседние карточки расходятся пружиной, активная плавно возвращается в слот
- Отключена обрезка ячеек, чтобы карточка не пропадала во время перетаскивания

### 🎛️ Управление городами
- При входе в режим выбора панель поиска плавно складывается, а заголовок меняется без вспышки старого текста
- Долгое нажатие только открывает редактор — ничего не выбрано заранее, отмечайте карточки вручную
- Кнопка удаления стала плавающей красной «пилюлей» с тенью и учётом нижнего отступа
- Панель выбора больше не мерцает при входе и выходе из режима
- «Текущая геолокация» переехала в шапку списка и прокручивается вместе с городами
- Повторяющиеся города не добавляются, а дубликаты в сохранённом списке схлопываются при загрузке
- Фоновое обновление погоды сохраняет порядок, заданный перетаскиванием

### 🔍 Экран погоды
- Новая компактная строка поиска: иконка поиска, анимированный placeholder, очистка, геолокация и меню в одном ряду
- Поле очищается после успешного поиска, клавиатура скрывается
- Весь экран прокручивается целиком: поиск, карточки и прогноз
- Убран отдельный заголовок «Погода» — меню переехало в строку поиска
- Обновлены отступы safe area и поведение статус-бара

### ⚙️ Сборка и зависимости
- Expo SDK 57 → 58, React Native 0.86 → 0.88, React 19.3
- Обновлены expo-модули, gesture-handler 3.3, reanimated 4.7, screens 4.30 и svg 15.16
- Плагин reanimated убран из babel.config.js — его подключает babel-preset-expo
- Реестр npm возвращён на registry.npmjs.org
- APK: `MyWeather-v1.0.23-arm64-v8a.apk` и `MyWeather-v1.0.23-armeabi-v7a.apk` ниже, во вложениях
